# 🔀 suss-diff: show a worktree's branch diff in a tab beside the agent

`/suss-diff` opens `gdiffbranch` for a worktree in a new iTerm tab right of the calling agent's
tab, and focuses it, so David reviews an agent's branch with one command.

- Phase 1: `open_diff_tab.md`
- Phase 2 (later): focus an existing tab that already shows that worktree's `gdiffbranch` instead of opening another
