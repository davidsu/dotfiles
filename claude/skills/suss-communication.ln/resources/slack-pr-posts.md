# Posts about pull requests

- **New PR:** the PR link on line 1, then one line (~15 words) on what it does.
- **Re-review nudge / review reply:** the PR link, then one line per review comment:
  `[comment name](comment link) -> outcome in plain words`.
  - Follow-up: `-> [follow-up, tracked](task url)`.
  - Open question: `-> need your input: <the problem, one sentence>. How should this work?`
- **Questions carry the problem only:** no options, no recommendation, every sentence verified.
- **Code links** are GitHub blob URLs pinned to a commit sha, with `#L<line>`.
- **No @tag** in a thread the reviewer already owns: they get the reply anyway.
- **Screenshots** go in with `--image`. Previews of a private repo show a broken image, which is
  one reason `send` turns link previews off.
